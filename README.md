# Casa en común

Aplicación familiar para registrar aportaciones e ingresos compartidos y consultar los gastos por mes, categoría y subcategoría.\n\nLa web y la copia local usan un PIN compartido para entrar. Las acciones quedan asociadas a una sola cuenta, por lo que no se distingue cuál de los dos ha registrado un movimiento. El PIN no se guarda en este repositorio; para configurarlo o cambiarlo, usa «He olvidado el PIN» en la pantalla de acceso. Los movimientos se almacenan en Supabase con Row Level Security.
